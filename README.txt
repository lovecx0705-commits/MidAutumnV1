丙午中秋 · 云台三谜｜PNG图片版

使用方法：
1. 双击 index.html，即可在浏览器打开小游戏。
2. images 文件夹里的图片全部改为普通 PNG，方便直接替换。
3. 你想换自己的图片时，不需要修改代码：
   - 首页图片 → 覆盖 images/cover.png
   - 第一谜 → 覆盖 images/riddle-1.png
   - 第二谜 → 覆盖 images/riddle-2.png
   - 第三谜 → 覆盖 images/riddle-3.png
   - 通关页 → 覆盖 images/ending.png
4. 关键点：你的新图片只要改成上面的同名 PNG，覆盖旧文件即可。
5. 建议：
   - cover.png：横图，16:9 左右
   - riddle-1/2/3.png：横图，16:9 左右
   - ending.png：横图，16:9 或 2:1
   网页会自动裁切适配。
6. 游戏允许：直接猜题 / 查看提示 / 猜不出直接揭晓答案 / 继续下一题。
